## Claude Desktopで随時参照する系（自動収集はしていない）
台本を書く前に、必要に応じてweb検索で参照する。

| サイト | 用途 | 備考 |
|---|---|---|
| [名探偵コナン考察・図解](https://conan-zukai.com/) | 謎解き型のネタ元。組織図・年表など図解付き考察 | robots.txtで自動アクセス禁止。人間が読む・検索結果経由での参照のみ |
| [アニメイトタイムズ](https://www.animatetimes.com/news/list.php?keyword=名探偵コナン) | 裏話暴露型・ランキング型のネタ元。キャラまとめ記事が豊富 | |
| [ピクシブ百科事典](https://dic.pixiv.net/a/名探偵コナン) | 名前の由来シリーズの裏取り。キャラ設定・元ネタ情報 | |
| [名探偵コナンWiki（Fandom）](https://meitantei-conan.fandom.com/ja/wiki/) | 事件経緯・登場人物の事実確認 | |
| [Wikipedia](https://ja.wikipedia.org/wiki/名探偵コナン) | 基本情報の一次ソース | |

## 使い方の目安
台本を書く前に「このネタ、ピクシブ百科事典で裏取りして」のようにClaude Desktopに頼むと、
該当ページをweb検索で調べてから台本に反映してくれる。
